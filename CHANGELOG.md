CHANGELOG
=========

0.8.1 - 2026-08-04
------------------

This release adds wheels and test coverage for Python 3.15, including
free-threaded builds, and updates PyO3 and Maturin for compatibility with the
new interpreter.

0.8.0 - 2026-07-17
------------------

This release updates PyO3 to 0.29, incorporating fixes for
RUSTSEC-2026-0176 and RUSTSEC-2026-0177. It also drops support for PyPy 3.9
and 3.10, which are no longer supported by PyO3.
